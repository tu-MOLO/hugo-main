浏览器里的民乐作品，常见做法是加载采样音频。这个项目反过来：**一个音频采样都没有**，高胡、扬琴、潮州筝的音色全部由声学模型实时算出来。

仓库：<https://github.com/tu-MOLO/lingnan-sizhu-studio>
在线体验：<https://tu-molo.github.io/lingnan-sizhu-studio/>

<!--more-->

## 四个模块，一个闭环

| 模块 | 做什么 |
|---|---|
| 粤鸣坊 | 在工尺音位上点奏三件乐器，音色实时合成 |
| 琴韵处 | 对着麦克风哼唱或拉奏，实时识别音高并换算成工尺字，画音高曲线 |
| 乐律战 | 跟着《雨打芭蕉》《步步高》《彩云追月》的工尺谱跟弹视唱，打分 |
| 释古法 | 交互式对照工尺谱、潮州二四谱与正线 / 反线 / 乙反 / 活五调式 |

顺序上是“听 → 辨 → 谱 → 奏”，每一块都对应一个真实的学习动作，而不是四个互不相干的演示页。

## 声音是怎么算出来的

打弦乐器（扬琴、潮州筝）用改进的 **Karplus-Strong 数字波导**：

- 分数延迟（fractional delay）让连续滑音不掉帧
- 环路低通模拟弦的能量耗散
- 按振动周期算的 T60 衰减补偿，还原“高频先死、低音余音更长”
- 扬琴双弦 ±4 音分微失谐做出合唱感，再叠琴竹 / 指甲的击拨瞬态
- 每个音离线确定性渲染成 `AudioBuffer` 并按音高缓存，避免实时算崩

高胡没有沿用 Karplus-Strong，因为**弓弦不是衰减型激励**：用 `PeriodicWave` 的 13 次谐波搭钢弦声源，循环滤波粉噪模拟弓毛摩擦，琴筒与蟒皮用 1100 / 2300 / 3800 Hz 共振峰加 7 kHz 空气高频峰做“只增强、不滤除”的整形——这是音色通透不发闷的关键。演奏上支持连弓 75 ms 换把滑音、起弓绰音、延迟启动的 5.2 Hz 揉弦。

空间感来自程序化生成的 2.8 s 厅堂脉冲响应，干声与卷积并行后过总线压缩，保证多音齐发不削波。

## 识谱用的不是模型

麦克风那一路是纯信号处理：时域自相关（ACF）+ 抛物线插值估计基频，再按当前调式（正线 1=C 或五声羽调 1=D）映射到最近的工尺字，同时给出音分偏差。没有后端、没有 API Key，打开网页就能用。

## 工程面

- Vite + TypeScript，`base: './'`，产物是纯静态文件，可直接扔到 GitHub Pages / Vercel / Cloudflare Pages
- Electron + electron-builder 打包 Windows 便携版与 NSIS、macOS dmg、Linux AppImage
- 59 项单元测试覆盖乐理换算与声学参数，推 `main` 自动构建发布，推 `v*` 标签三平台并行出 Release

## 为什么值得做

工尺谱是活着的记谱法，但对着纸面很难听见它。把“看谱—出声—跟弹—纠错”压缩在一次点击里，比写十篇科普更能让人记住它长什么样。
